# Proposed application abstract

I am developing VietEvidence Lab, a non-commercial student project studying whether Vietnamese technical assistants can answer for the correct device revision and abstain when document evidence is missing or misleading. The AI-assisted prototype includes 96 controlled technical cases and a separate 40-case exploratory XQuAD branch, with 816 recorded local inference outputs from two Qwen models under three fixed prompting strategies; synthetic labels are programmatic and natural-text negative labels still require independent review. Over the next 6–12 months, I plan to validate labels, expand to legally reusable Vietnamese technical documents, and compare evidence-checking methods across additional model families and retrieval conditions using held-out tests, uncertainty estimates, and resource measurements. I plan to use Google Antigravity to develop and test experiment adapters, manage reproducible runs, and analyze failure cases, with reviewed data, reusable evaluation software, and a technical report as intended public outputs.

This draft reports completed local-model work and future plans. No application submission is implied.
